**What it is**  
GrubShelf helps households track the pantry, share shopping lists, set budgets, and get expiry reminders—less waste, clearer spending.

**What’s in the app**  
Sign-in (Apple, Google, email), shared household, pantry (barcode/catalog/manual), shopping lists, home overview, budgets & insights, family invites, settings, and a shopping-list widget.

**What to do**  
Use it like you would in real life for a week or two—no checklist.

**Feedback**  
In TestFlight, use Send Feedback. Tell us: frictions (stuck, confused, too many steps), improvements, and features you’d want added or removed. Device model + iOS version + a screenshot help. Thanks!
